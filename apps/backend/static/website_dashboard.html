🌐 External Website Integration API Reference

Use the following REST API endpoints to fetch live Tally / BUSY data directly into your custom website, web app, or portal: 

# 1. Fetch Summary Stats for Web Widgets
GET http://127.0.0.1:8000/api/v1/website/dashboard/summary

# 2. Fetch Stored Ledgers for Website Display
GET http://127.0.0.1:8000/api/v1/website/entities/LEDGER?page=1&page_size=50

# 3. Fetch Stored Stock Items with Search Query
GET http://127.0.0.1:8000/api/v1/website/entities/STOCK_ITEM?search=Item

# 4. Trigger Live Tally Pull + Save to DB + Return Data
POST http://127.0.0.1:8000/api/v1/website/sync-and-store
